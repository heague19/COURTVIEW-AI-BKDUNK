## 5. UI 캘리브레이션 가이드

### 5.1 설치 흐름

```
1. 카메라 8대 설치 완료
2. 각 카메라 라이브 피드 확인
3. 카메라별 캘리브레이션 실행:
   a. 카메라 피드 위에 코트 도면 오버레이
   b. 보이는 키포인트 순서대로 클릭 (최소 4개)
   c. 안 보이는 키포인트는 스킵
   d. 완료 → API 전송
4. 8대 모두 완료 → 경기 시작 가능
```

### 5.2 API 엔드포인트

```
POST /api/v1/camera/{camera_id}/calibrate/manual

Request Body:
{
  "camera_id": "cam_0",
  "pixel_points": [[886, 501], [1854, 719], ...],
  "court_points": [[28.0, 0.0], [28.0, 15.0], ...],
  "court_standard": "fiba"
}

Response:
{
  "camera_id": "cam_0",
  "success": true,
  "quality_score": 1.0,
  "mean_reproj_error_px": 0.47,
  "inlier_count": 9,
  "total_points": 9,
  "message": "캘리브레이션 완료 (품질: 1.00, 오차: 0.47px)"
}
```

### 5.3 품질 기준

| 등급 | 재투영 오차 | 설명 |
|------|:----------:|------|
| 우수 | < 1.0m | 프로덕션 사용 가능 |
| 양호 | 1.0 ~ 3.0m | 사용 가능, 재시도 권장 |
| 미흡 | 3.0 ~ 5.0m | 재캘리브레이션 필요 |
| 불량 | > 5.0m | 사용 불가 |

### 5.4 카메라별 보이는 키포인트 (참고)

```
cam1(좌상)     cam2(상중좌)  cam3(상중우)     cam4(우상)
     ┌─────────────┬─────────────┐
     │    ○(골대L)  │   ○(골대R)  │
     │             │             │
     └─────────────┴─────────────┘
cam5(좌하)     cam6(하중좌)  cam7(하중우)     cam8(우하)
```

각 카메라는 코트의 일부만 보입니다. **보이는 포인트만 클릭**하면 됩니다.

## 6. 저장 경로

```
configs/calibration/
  ├── cam_0.json           # cam1 영상 매핑 (picker 규약)
  ├── cam_1.json           # cam2 영상 매핑
  ├── ...
  ├── cam_7.json           # cam8 영상 매핑
  └── pixel_points.json    # 클릭한 원본 픽셀+코트 좌표
```

각 JSON 구조:
```json
{
  "camera_id": "cam_0",
  "homography": [[...]],              # 3×3 행렬 (픽셀 → 코트 m)
  "inverse_homography": [[...]],      # 코트 → 픽셀 역변환
  "inlier_mean_error_m": 0.68,
  "quality_score": 1.0,
  "point_names": ["corner_TL", ...],
  "pixel_points": [[886, 501], ...],
  "court_points": [[0.0, 0.0], ...]
}
```

경기 시작 시 `CalibrationLoader`가 자동 로드 → `MultiViewPlayerTracker` + `DetectionFusion`에서 공유 사용.

> **picker 규약**: `cam_0.json` = 영상 파일 `cam1.mp4`에 대응 (인덱스 vs 파일명 차이 주의)
